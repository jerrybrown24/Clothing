# Mentor skill — install

One file: `mentor/SKILL.md`. Memory is created automatically on first use.

**Claude Code (any machine):** copy to `~/.claude/skills/mentor/SKILL.md` (all projects) or
`<project>/.claude/skills/mentor/SKILL.md` (one project). Then run `/mentor`.

**Claude.ai:** Settings → Capabilities → Skills → upload the `mentor` folder (zip it first).
Or paste the body of SKILL.md into a Project's instructions. Chat-only has no file access, so it will
hand you a memory block to save and paste back each session.

**Any other Claude/LLM setup:** paste the file as the system/custom instructions.
